## Available Commands

| Command | Description | Example |
|---|---|---|
| `/elem` | Look up chemical elements | `/elem Na` |
| `/cc` | Search chemical compounds | `/cc H2O` |
| `/cf` | Search chemistry formulas | `/cf molarity` |
| `/molar` | Calculate molar mass | `/molar H2O` |
| `/molarity` | Calculate molarity | `/molarity 2 0.5` |
| `/ph` | Calculate pH | `/ph 0.001` |
